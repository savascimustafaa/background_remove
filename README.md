# Remove Background 🖼️

Bu proje, görsellerin arka planını hızlı, otomatik ve etkili bir şekilde kaldırmak için geliştirilmiş bir araçtır. İster portre fotoğrafları, ister ürün görselleri olsun, tek bir işlemle arka planı temizleyerek objeyi ön plana çıkarmanızı sağlar.

## 🚀 Özellikler

- **Hızlı İşlem:** Görsellerin arka planını saniyeler içinde temizler.
- **Yüksek Hassasiyet:** Objelerin sınırlarını doğru bir şekilde algılar.
- **Çoklu Format Desteği:** JPEG, PNG, WEBP gibi yaygın görsel formatlarını destekler.
- **Kolay Kullanım:** Karmaşık ayarlara gerek kalmadan doğrudan sonuç verir.
